    Method

    Backbone

    K-Means clusters the standardised segment features \(\mathbf f = [\lambda_E\hat x,\ \lambda_E\hat y,\ \lambda_\theta\hat m,\ \lambda_\tau\hat i]\) with plain Euclidean distance.

    Choosing k

    Rule for choosing k
    \[r_k=\frac{|J_{k+1}-J_k|}{|J_k-J_{k-1}|}\] \(J_k\) is the distortion with \(k\) clusters. The chosen \(k\) is the first one with \(r_k<m_{ratio}\). If none qualifies, the app falls back to \(k=3\) and says so on the Choosing k tab.
    \[g_k=\frac{J_{k-1}-J_k}{J_1},\qquad k^*=\max\{k : g_k\ge\tau\}\] \(g_k\) is the share of the one-cluster cost \(J_1\) removed by adding the \(k\)-th cluster. The chosen \(k\) is the largest one whose cluster still removes at least \(\tau\). If none does, \(k=1\).

    Segments and clusters

    The number of regimes you ask the algorithm for. It always returns exactly \(k\) clusters, whether or not the data contains that many physical flow regimes.
    Points per segment. The data are cut into \(\lfloor n/w \rfloor\) non-overlapping segments and each segment gets one label. The last \(n \bmod w\) points are not clustered (grey in the plots).

    Dissimilarity weights

    \[\tilde d_{E,ij}=\frac{1}{D_{E,\max}}\sqrt{\sum_{k=1}^{w}(x_{ik}-x_{jk})^2+(y_{ik}-y_{jk})^2}\] Separates segments that sit far apart on the normalised log-log plot.
    \[\tilde d_{\theta,ij}=\frac{\left|\arctan m_i-\arctan m_j\right|}{90^\circ}\] \(m\) is the log-log slope of the derivative in each segment. Segments with different slopes behave like different flow regimes.
    \[\tilde d_{\tau,ij}=\frac{\max(0,\ |i-j|-1)}{T_{\max}}\] Penalises grouping segments that are far apart in time, which keeps each regime one continuous interval.
    \[\tilde d_{\Lambda,ij}=\begin{cases}-1 & \text{both segments in an inverted-V block}\\ 0 & \text{otherwise}\end{cases}\] Pulls the wellbore-storage hump (a rising segment followed by a falling one) into the same cluster.

    Additional parameters

    A block of \(p\) consecutive segments is flagged when it contains a pair with \(m_j>0\) followed by \(m_{j+1}<0\). Flagged segments are shaded in the Segmentation tab.
    If an inverted-V block starts at segment index \(i \le i_{early}\) (the first segment is 0), the flag is extended back to the first segment, so the unit-slope rise before the hump joins the hump. At the far left the slider is off. The Segmentation tab shows which segments end up flagged.
    Advanced
    For adjacent segments with curvature radius \(R=\frac{(1+\bar m^2)^{3/2}}{|\Delta m/\Delta x|}>2\Delta x\), the dissimilarity is reduced by \(\delta\).
    If two adjacent segments both have \(|m|<m_0\), their dissimilarity is replaced by \(0.1\,\lambda_E\tilde d_E\), which strongly favours keeping a flat plateau together. (The original script used \(m_0=1\).)
